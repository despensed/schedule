Простой сайт для просмотра школьного расписания
Я использовал для написания:
  HTML, CSS, JavaScript и совсем немного Python

---

## Начинка сайта:

- Показывает текущий урок или перемену с таймером до конца (+3 разных стиля)
- Самостоятельно считает время до следующего урока и его конца
- Можно посмотреть расписание на каждые из пяти учебных дней
- Подсвечивает текущий урок в списке чуть ниже таймера и делает серым прошедшие
- Наличие большого количества кастомизации (тема, свои цвета и довольно гибкая настройка фона)
