 # Расписание

🔗 [https://despensed.github.io/schedule/](https://despensed.github.io/schedule/)

Простой сайт для просмотра школьного расписания.
Сделан на HTML, CSS, JavaScript — и совсем немного Python. (+ помощь Deepseek)

---

## Что умеет

- Показывает текущий урок или перемену с таймером до конца. Три стиля на выбор: **кольцо**, **полоса**, **сердца**.
- Сам считает время до следующего урока и до его конца.
- Если открыть другой день недели — покажет время до его первого урока.
- Расписание на каждый из пяти учебных дней. Текущий урок подсвечен, прошедшие — приглушены.
- Кастомизация: тема, свои цвета, фон (орбы / частицы / градиент), свечение таймера, обводка и анимация сердец.
